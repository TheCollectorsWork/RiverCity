# River City

An iPhone poker adventure built with SwiftUI and SceneKit.

## Run

Open `RiverCity.xcodeproj` in Xcode, select the RiverCity scheme and an iPhone simulator, then Run. Deployment target: iOS 17 or later.

The development build starts in Test mode with unlocked locations and a separate save. Switch to Story mode from the city screen for progression.

## Contents

- `RiverCity.swift`: app, city, tournament interface and profile.
- `Poker.swift`: Texas Hold’em engine and save models.
- `Art/`: game artwork.
- `IMPLEMENTATION_STATUS.md`: implemented features and remaining PRD work.

This is a work-in-progress prototype, not the complete release.
